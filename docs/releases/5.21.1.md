# HakuX-Advanced 5.21.1 — Super Trooper: Default-on Hotfix

Rogue Trooper revision 1 (5343000E.1) now automatically enables the sound-bank
loading compatibility fix, offline and with online protection ON. No patch
import or first-run menu change is required. Existing explicit OFF choices are
respected; the switch remains under Mods & cheats for troubleshooting.
Old builds removed OFF entries instead of storing them, so an absent entry
now uses the ON default. This cannot distinguish an old removed OFF from unset.

Install over Advanced without uninstalling, then fully restart the game.
Version 1.3.0-advanced5.21.1, code 48. Native binaries unchanged from 5.21.
Trainers/cheats remain blocked in protected sessions. Protected-online device
testing remains pending. See VALIDATION.json in the kit for build evidence.
