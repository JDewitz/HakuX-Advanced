## New in 5.19

Merged all 14 upstream commits after official 1.3.0 and rebuilt the native core and C/C++ dependencies. Changes include correct texture coordinates for small render targets at elevated resolution, Mali W-buffer/timeline/timestamp/presentation workarounds, more precise malisx2 detection, dynamically sized swapchain image arrays, Mali custom-driver loading and corrected driver advice. The existing pinned Slang C API is unchanged.

## Advanced features included

- Mappable uncapped fast forward with hold/toggle mode and quiet `>>` OSD; additional quick-save/load, pause, screenshot, benchmark and Next Shader mappings.
- Two-pane pause/save-state browser with ten slots, screenshots, timestamps and save/load/delete controls.
- Five-level performance HUD with sampled frame-time graph and actual active/pending/fallback shader identification.
- RetroArch Slang preset browsing, downloading, ZIP import, parameters, per-game settings and shader-pack deletion.
- RenderUpdate modes: adaptive sharpening, SMAA, SMAA + sharpening, FXAA, fast bicubic, FSR 1 EASU, EASU + RCAS and FXAA + FSR. Adjustable search budgets, sharpness, subpixel smoothing and bicubic shape.
- Separate RenderUpdate preprocessing and CRT/custom post-render selections, with explicit experimental stacking opt-in. Complex unsupported combinations fall back safely; native FXAA/SGSR remain separate bypassed branches while Slang is active.
- Shared importable color themes, live theme preview, five library views and trainer/configuration badges.
- EvoX ETM trainer browser, import-time metadata indexing and per-game remembered options.
- Halo revision 8 (`4D530004.8`) high-pool Auto/On/Off compatibility controls, guarded imported patch support and online-play protection.
- Advanced CPU/RAM/driver profiles, presentation controls, benchmarks, memory tools, renderer inspection and diagnostic export.

## Validation and limitations

The APK assembled and its existing signing certificate was verified. **148 JVM tests and 15 HLE suites passed**, alongside native pool-placement/Advanced regressions. [GitHub host checks passed](https://github.com/JDewitz/HakuX-Advanced/actions/runs/41804544445). The rebuilt core preserves all 29 checked JNI/SDL entry points. These host checks do not establish real Android GPU behavior.

**5.19 device testing is still pending.** No Snowblind skybox fix, measured Halo speed increase, 60 fps unlock, new volumetrics or new reflections is claimed. Slang requires the existing native Vulkan 1.3 path. Heavy shaders and stacking can reduce performance or expose driver faults. No rewind, automatic dynamic resolution, texture replacement or forced anisotropic filtering is added here.

Protected online sessions block managed trainer/cheat/gameplay-mod injection and memory tools; offline trainer sessions force Xbox networking off. Save-state loading is allowed online, but existing snapshot memory is not scrubbed of earlier trainer effects. Use trainer-free states for protected testing. Imported-patch sessions retain their separate state restrictions. The production online-approved imported-patch registry is empty.

## Installation and first checks

Back up important console/game saves with the app's existing tools. Install the APK over the matching Advanced/Themes test app; the application ID and signing certificate are unchanged. It installs separately from official hakuX. Do not uninstall your working app just to try this update.

First retest Halo revision 8 with pool placement on Auto, then Snowblind with shaders Off at 1x and your usual scale. Check pause/HUD, state loading, a known-good shader and finally an opted-in pre/post stack. Report device/GPU, driver/version, game identity/revision, settings, steps and exported logs. See INSTALL-AND-TEST.md in the kit.

The kit contains source and pinned native dependency snapshots, build instructions, validation metadata and SHA-256 checksums. No signing key, Xbox dashboard, BIOS, game image, console/account data or trainer collection is bundled. Project and dependency attribution/licenses are retained in the source distribution.
