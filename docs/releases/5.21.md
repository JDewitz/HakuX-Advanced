# HakuX-Advanced 5.21

- Integrates the 5.2.h Rogue Trooper sound-bank loading workaround into Advanced.
- Handles the selected cache file on Xbox cache partitions 3, 4 and 5. The
  first regular preview missed Partition4; Preview 2 corrected it and received
  a successful user test on 2026-11-21.
- Adds a reusable per-game, per-filename cache-write rule through Mods & cheats,
  with one-time enable/arm/match logging and native regression tests.
- Shortens the README and consolidates current compatibility/testing notes.
- Retains Advanced 5.20 rendering, XISO handling and existing compatibility fixes.

## Install and use

Install the signed arm64 APK over regular HakuX-Advanced; do not uninstall.
Existing settings and console data are retained. The separate experimental
5.2.h app keeps its own data.

For Rogue Trooper revision 1 (5343000E.1), select Offline mode, enable
**Mods & cheats → Sound bank loading fix**, then fully exit and cold start.
The mod remains off by default. Protected online sessions exclude this mod.
No additional patch download is required.

## Validation and scope

The user confirmed the Preview 2 integration works. Release 5.21 reuses all
11 native libraries byte-for-byte from that confirmed APK; this promotion
changes version/branding and documentation, with an updater regression test.
