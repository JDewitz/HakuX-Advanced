The earlier offline-only kit is on hold. Test the protected-online integration
before regenerating the final release package.

- Integrates the 5.2.h Rogue Trooper sound-bank loading workaround into Advanced.

- Shortens the README and consolidates current compatibility/testing notes.

## Install and use

Install the signed arm64 APK over regular HakuX-Advanced; do not uninstall.
Existing settings and console data are retained. The separate experimental
5.2.h app keeps its own data.

For Rogue Trooper revision 1 (5343000E.1), enable
**Mods & cheats → Sound bank loading fix**, then fully exit and cold start.
The mod remains off by default. Online protection may remain on for this specific native compatibility rule;
trainers and cheats remain blocked. Protected-session device testing is pending.
No additional patch download is required.
